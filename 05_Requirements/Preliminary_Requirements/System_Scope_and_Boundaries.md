# System Scope and Boundaries

## 1. Purpose

This document defines what the proposed system includes and excludes to prevent uncontrolled project expansion.

## 2. In Scope

- IoT temperature monitoring.
- IoT humidity monitoring.
- Sensor data transmission.
- Backend processing.
- Environmental data storage.
- Real-time/near-real-time dashboard.
- Historical monitoring.
- Environmental threshold monitoring.
- Environmental alerts.
- Produce batch registration.
- Produce movement and handling events.
- QR-code generation and scanning.
- Produce traceability history.
- Selected Blockchain cold-chain/traceability records or integrity proofs.
- Blockchain verification.
- System testing and evaluation.

## 3. Out of Scope

- Automated refrigeration control.
- Automated vehicle driving/control.
- Commercial payment processing.
- Full enterprise resource planning.
- Automated customs clearance.
- Commercial-scale fleet management.
- Automated physical handling of produce.
- Nationwide production deployment.
- Full commercial logistics management.

## 4. System Boundary

The prototype focuses on monitoring and traceability after produce enters the defined cold-chain monitoring process.

## 5. Scope Protection Rule

Optional features must not delay completion and evaluation of the four approved objectives.
