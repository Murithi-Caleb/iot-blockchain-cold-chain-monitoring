# 7. Challenges Encountered

During today's activities, a few minor challenges were encountered.

The GitHub repository had been initialized only with a README file, requiring the complete project directory structure to be manually created after cloning.

Additionally, Git does not track empty directories, meaning placeholder files had to be introduced to preserve the intended project structure within the repository.

These challenges did not significantly affect progress and were successfully resolved.

---

# 8. Solutions Applied

The project directory structure was manually created inside the cloned GitHub repository using Visual Studio Code.

Placeholder `.gitkeep` files were added to empty directories to ensure Git tracks the complete project structure.

A `.gitignore` file was also created to exclude unnecessary files and folders from version control, improving repository cleanliness and maintainability.

---

# 9. Lessons Learned

Today's mission reinforced several important software engineering principles.

I learned the importance of establishing a well-organized project structure before writing any production code. A properly structured repository significantly improves maintainability, collaboration, and project management.

I also learned that Git does not automatically track empty directories, making `.gitkeep` files necessary during the early stages of development.

Furthermore, I recognized that proper planning and documentation are essential components of successful software engineering projects and should be treated with the same importance as programming itself.
